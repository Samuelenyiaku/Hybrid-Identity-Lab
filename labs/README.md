# Lab Exercises

Each exercise should state its objective, prerequisites, procedure, expected result, observed result, and cleanup / rollback steps.

1. **Domain controller health** — validate AD DS, DNS, and Netlogon.
2. **Domain client validation** — verify DNS resolution, DC discovery, and secure channel.
3. **Entra tenant setup** — document tenant context and baseline security.
4. **Hybrid identity pilot** — configure a small, intentional sync scope and validate one test identity.
5. **Okta SSO** — test a non-production application and record both allowed and denied access.

Cloud exercises are planned until their configuration and evidence are added. Never place secrets in exercise files.
